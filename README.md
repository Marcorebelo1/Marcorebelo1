## 🚀 Selected Work

### 🧠 FUC → ELM · AI-Powered Academic Data Pipeline

End-to-end pipeline developed as my undergraduate final project and continued within **Blockchain.PT**.

The system transforms unstructured academic documents into interoperable **European Learning Model (ELM)** data through a multi-stage AI-assisted processing workflow.

**Highlights**

* PDF extraction and conditional OCR
* Text cleaning and document normalization
* Automatic section detection
* Local LLM integration through **Ollama**
* Semantic information extraction
* Structured LLM outputs and validation
* Canonical data integration
* Mapping to **JSON-LD / ELM**
* Semantic validation using **LOQ / SHACL**
* Evaluated on **39 real academic documents**
* **39/39 ELM outputs successfully validated**
* Undergraduate final project grade: **20/20**
* Resulted in a research paper submission

**Tech:** Python · Ollama · LLMs · OCR · FastAPI · JSON-LD · RDF · SHACL · ELM
